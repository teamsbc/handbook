# Intended Audience

TeamSBC is currently for tinkerers: people who enjoy exploring how operating systems work and trying different ways to put them together. This includes Linux enthusiasts, single board computer hobbyists, administrators experimenting with deployments, and developers interested in contributing to the distribution.

The handbook is written for people who want to install and use TeamSBC, understand its design choices, or build on the work already here. You do not need to know every tool TeamSBC uses before getting started.

## What You Should Know

Some familiarity with Linux and the command line will help. The instructions assume that you can run terminal commands, work with files, and identify the storage device you want to install an image onto. The administration chapters also introduce tasks involving users, services, and networking.

There is room to learn as you go. If a step is unclear or an explanation assumes too much, [ask the community](./community.md). Those questions can help us improve the handbook for the next person, too.

## What to Expect

TeamSBC is still developing toward a stable form. Configuration and procedures may change, and parts of the documentation are incomplete. In particular, maintenance instructions for Makalu are still being written. Expect some experimentation and troubleshooting as you explore the project.

If you have opinions about operating systems and how they should be put together, especially for single board computers, you are more than welcome to join in and share them.
