# Variants

TeamSBC variants offer different approaches to maintaining devices. The handbook separates maintenance instructions for **Lhotse** and **Makalu**.

## Lhotse

The Lhotse variant is package-based. This is probably the type of setup that you are most familiar with if you've previously used any other Linux distributions.

See [updating Lhotse](../maintenance/lhotse/updating.md) and [installing applications on Lhotse](../maintenance/lhotse/installing-applications.md).

## Makalu

Makalu is the image-based variant. Its maintenance procedures are being documented.

See [updating Makalu](../maintenance/makalu/updating.md) and [installing applications on Makalu](../maintenance/makalu/installing-applications.md).
